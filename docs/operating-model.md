# Operating model

## Goal

Prove that one small technical resource site can generate real economic value from high-intent traffic without meaningful fixed infrastructure cost.

## Initial monetization channels

1. Compute-provider referrals
2. Cloud/developer referrals
3. Useful calculators/tools leading to commercial actions
4. Later: paid data/API access
5. Later: agent-executed jobs

## Rules

- One domain.
- No generated-page explosion.
- Every page must have a concrete reason to exist.
- Prefer primary sources and reproducible calculations.
- Clearly mark referral relationships.
- Do not hide mining, downloads, redirects, or executable behavior.
- Never collect credentials or private keys.

## Success metrics

Track:

`revenue / visitor`

`revenue / qualified click`

`revenue / frontier-model call`

`revenue / month of infrastructure`

The experiment should not add recurring spend merely to increase page count.
