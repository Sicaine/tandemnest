# Account checklist before launch

## Identity / site
- [ ] Choose one domain
- [ ] Create GitHub repository
- [ ] Create Cloudflare account
- [ ] Add domain to Cloudflare
- [ ] Create Cloudflare Pages project
- [ ] Verify HTTPS
- [ ] Add Google Search Console

## Monetization
- [ ] Create dedicated XMR receiving address
- [ ] Create RunPod account and obtain referral URL
- [ ] Create DigitalOcean account and obtain referral URL / apply to affiliate program
- [ ] Add only public referral URLs to `config.yaml`
- [ ] Add a visible affiliate disclosure

## Content
- [ ] Write one genuinely useful page per experiment
- [ ] Add source links and current pricing dates
- [ ] Include original calculations / benchmarks
- [ ] Avoid copied provider marketing copy
- [ ] Avoid generating dozens of near-identical pages

## Measurement
- [ ] Verify server access logs or privacy-respecting analytics
- [ ] Track outbound clicks
- [ ] Track referral conversions where provider dashboards allow it
- [ ] Track search impressions in Search Console
- [ ] Record revenue and credits separately
