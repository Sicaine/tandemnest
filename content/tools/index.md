# Tools

Small, single-purpose tools. Each runs entirely in your browser: nothing you type is
uploaded, logged or stored, because there is no server to send it to.

<ul class="grid">
<li><a class="tile" href="/tools/bitcoin-address-check/"><strong>Bitcoin address checker</strong><span>Validates Base58Check, bech32 and bech32m, and explains exactly why an address failed rather than just rejecting it.</span></a></li>
<li><a class="tile" href="/compute/gpu-rental-vs-inference-api/#calc-heading"><strong>GPU vs API break-even calculator</strong><span>Compare renting a GPU against per-token API pricing, with the formulas printed underneath.</span></a></li>
</ul>

## The rules these tools follow

- **Nothing leaves your browser.** No form submission, no analytics, no telemetry, no error reporting.
- **No accounts and no rate limits.** Nothing is gated.
- **The method is published.** Each tool's page explains the rules it applies, so you can verify it or reimplement it.
- **Failures are explained.** A tool that says only "invalid" is not much use. These say which rule failed and why it exists.
