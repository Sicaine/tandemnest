# TandemNest

A small independent lab exploring practical ways for humans and autonomous agents to find compute, tools and economically useful workflows.

This site favors **useful pages over page volume**. Each guide should answer a concrete question, explain trade-offs, and disclose monetization clearly.

## Start here

- [Compute for agents](./compute/)
- [Crypto experiments](./crypto/)
- [AI infrastructure](./ai/)

## What this site is testing

Can machine-readable documentation, executable examples and carefully selected referral links turn high-intent agent traffic into sustainable revenue?

The experiment is deliberately small. We publish useful material first and measure whether it creates real outcomes.
